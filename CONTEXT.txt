WHAT WE ARE BUILDING
--------------------------------------------------------------------------

CollabSpace is a premium collaborative document workspace inspired by
Google Docs + Notion, but with its own unique editorial visual identity.

KEY FEATURES:
- Create, upload, organize documents
- Real-time collaboration with block-level editing locks
- Workspace management with invitations and roles
- Context chat panel inside document editor
- Role-based access: ADMIN / USER
- Clean, minimal, editorial design (NOT generic AI SaaS look)

DESIGN IDENTITY:
- Warm off-white/cream background: #FAF8F5
- Obsidian dark text: #1C1917
- Amber accent: #D97706
- Cream containers: #F4F0EA
- Editorial typography: Playfair Display (headings) + Plus Jakarta Sans (UI)
- Generous whitespace, document-first layouts

HOW THE APP WORKS RIGHT NOW
--------------------------------------------------------------------------

1. User visits http://localhost:5173/ → sees editorial Landing Page
2. Clicks "Start Collaborating" or "Sign In" → Book Auth Modal opens
3. Logs in with mock credentials → Lands on User Dashboard
4. Dashboard has left sidebar (Home, My Docs, Shared, Workspaces, etc.)
5. Can create new documents (Blank/Template/Markdown/DOCX/PDF)
6. Can upload documents with drag-drop (simulated progress states)
7. Can star, rename, delete, restore documents
8. Can switch between Grid and List views
9. Can search, filter by format, sort by date/title
10. Workspaces tab → shows workspace cards → click into workspace detail
11. Workspace detail has Overview, Documents, Members, Activity tabs
12. Can invite members with role selection
